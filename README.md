# 🛍️ E-Commerce Landing Page

## HTML & CSS Practice Project

A modern and visually appealing **E-Commerce Landing Page** built using **HTML5 and CSS3** as a practice project after completing my basic HTML and CSS learning.

I created this project by following free HTML & CSS tutorials and frontend development videos on YouTube and then practicing the concepts by building a complete e-commerce-style website.

This project helped me understand how different HTML and CSS concepts can be combined to create a modern product-focused website.

---

## 🌐 Live Demo

🔗 Live Website: https://fuyad254.github.io/E-Commerce-Website-/

---

## 📸 Project Overview

This project is a modern **E-Commerce Landing Page** designed to showcase products such as bags and watches.

The website includes a hero/banner section, product collections, company information, product cards, social media links, email subscription section, and footer.

The main focus of this project was to practice **HTML structure, CSS layouts, Flexbox, positioning, hover effects, shadows, buttons, and responsive UI concepts**.

The Bags Collection section displays multiple product cards.
